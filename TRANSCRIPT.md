# Agent session transcript

If you used a coding agent, put the session here — paste it in, or commit
whatever your tool exports alongside this file and link to it. Any readable
format is fine, and it does not need tidying up.

What we read it for is where you steered, where you overrode, and where you
decided the agent was wrong. It is not scored on prompting, and there is no
penalty for using one — we do.

If you didn't use an agent, replace this file's contents with a line saying so.
